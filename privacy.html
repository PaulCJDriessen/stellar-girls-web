Privacy policy

Effective 17 September 2026. Publisher: Paul Driessen (Stellar Girls).

This policy covers this website and the Stellar Girls Windows game. It is written for how the project actually works today — not for a hypothetical account server. If Steam Cloud, achievements, or store checkout go live later, those pieces are covered by Valve’s policies as well, and we will update this page.

1. This website

  • The site is static files hosted on GitHub Pages. We do not run a login, newsletter, or comment form here.
  • We do not set first-party analytics cookies. GitHub (and your browser, DNS, or ISP) may process technical data such as IP address and user-agent when you request pages. See GitHub’s privacy statement.
  • Pages load the Outfit font from Google Fonts. Google may receive your IP address. You can block third-party fonts; the site remains readable.
  • We do not sell personal data. We do not run ads.

2. The game (offline-first)

Stellar Girls is an Electron app. It does not require a Stellar Girls account.

  • Campaign save is a local file under the app’s Windows user data folder (saves/campaign.json). It stores progress, Trust, ★, lineup, and relationship flags needed to resume play.
  • Settings (volume, fullscreen, resolution) and a few “already taught this tip” flags live in the browser profile’s localStorage on your machine.
  • We do not operate a telemetry backend. The current build does not phone home for analytics.
  • Resetting progress from the in-game menu deletes the local campaign file we manage. It does not wipe your whole PC.

3. Steam (when you play through Steam)

If you install or buy via Steam, Valve processes purchase, Steam ID, overlay, and (when enabled) Cloud data under the Steam Privacy Agreement. Stellar Girls does not currently ship Cloud sync; if that lands, the save described above may be copied to Steam Cloud so you can restore it on another PC signed into the same Steam account.

4. Children

The game is intended for mature audiences (PEGI 16 / ESRB M target). We do not knowingly collect personal data from children. Do not create Steam or device accounts for the purpose of letting a child play this title.

5. Your choices

  • Uninstall the game to remove the application. Local saves/settings may remain in the user-data folder until you delete that folder.
  • Stop visiting this website. Clear your browser cache if you wish.
  • Use Steam’s own privacy and overlay settings when playing on Steam.

6. Contact

Questions about this policy: open an issue on the public site repository github.com/PaulCJDriessen/stellar-girls-web or contact the publisher through the Steam store listing for Stellar Girls once it is live.

We will post the date of any material change at the top of this page.
