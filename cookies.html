GitHub Pages (host)

Pages are served by GitHub. GitHub may process IP address, user-agent, and similar technical data as a processor/host, and may set its own cookies if you are logged into GitHub. We do not control those. See GitHub’s privacy statement and GitHub cookies.

Legal basis for using a host that processes connection data: Art. 6(1)(f) GDPR (legitimate interest in operating a public website). You may object by not visiting the site.
